# ⚡ FIT FEST

> Official repository for the **FIT FEST** Hackathon Project.

## 🚀 Overview
**FIT FEST** is an energetic, high-performance web platform built for fitness enthusiasts, challenge seekers, and festival participants.

## 🛠️ Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Code Quality**: ESLint

## 📂 Project Structure
```text
fit-fest/
├── src/
│   ├── app/            # Next.js App Router (pages, layouts, routes)
│   ├── components/     # Modular UI components
│   ├── hooks/          # Reusable React hooks
│   ├── lib/            # Utilities and helper functions
│   ├── services/       # API clients and external service adapters
│   └── types/          # TypeScript interfaces and data models
├── public/             # Static assets (images, icons)
├── package.json
└── tsconfig.json
```

## 🏃 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
